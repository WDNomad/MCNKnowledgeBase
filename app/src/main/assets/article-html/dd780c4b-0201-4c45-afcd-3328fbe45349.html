Голосовой робот

События (вебхуки и триггеры), связанные с работой Голосового робота.

Единый Envelope используется для всех событий: один channel соответствует одному event_type.

Содержание

  • Звонок объекту
  • Звонок клиенту

Общий формат события

Все события используют общую обёртку Envelope:

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; одинаков при повторных доставках и используется для дедупликации
dataobject✓Данные, специфичные для event_type

✓ — обязательное поле; — — необязательное.

Для каждого события приведены описание полей data и пример Payload.

Звонок объекту

VpbxRobocallObject - Голосовой робот: звонок

Событие: Событие из голосового робота
Payload: allOf — общий Envelope + данные события.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные, специфичные для event_type

data

ПолеТипОбяз.Описание
originateDatastring✓Данные инициации звонка (originateData)

robocallIdstring✓Идентификатор робоколла
userEventTypestring✓Дублирует event_type — тип события AMI UserEvent

privilegestring✓Уровень логирования/видимости события в Asterisk AMI
extenstring✓Extension диалплана, где сработало событие

channelStatenumber✓Код состояния Asterisk-канала (см. channelStateDesc)
callerIdNumstring✓Номер вызывающего абонента (Caller ID number)
systemNamestring✓ID Asterisk-сервера (номер хаба)

contextstring✓Контекст события
eventstring✓Дублирует event_type — служебное поле Asterisk UserEvent
calledNumberstring✓Номер вызывающей стороны
objectIdstring✓Идентификатор объекта
timestampnumber✓Время создания события
callIdstring✓Идентификатор звонка
linkedIdstring✓ID связанного звонка
callerNumberstring✓Номер звонящего абонента
dateReceivedAtUTCstring✓Время получения Kafka-коннектором в UTC, до микросекунд
eventTypestring✓Тип события
prioritynumber✓Приоритет текущего шага диалплана Asterisk
accountIdnumber✓Номер ЛС
channelStateDescstring✓Расшифровка channelState (например Up, Ring, Down)
callerIdNamestring✓Имя вызывающего абонента, если передано АТС/оператором
taskIdstring✓Идентификатор задачи робоколла
uniqueIdstring✓Уникальный ID call-leg, формат {systemName}-{timestamp}.{seq}
vpbxIdstring✓Номер Виртуальной АТС

✓ — обязательное поле; — — необязательное.
