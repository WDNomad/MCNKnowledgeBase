SMS

События (вебхуки и триггеры), связанные с отправкой и получением SMS-сообщений и их тарификацией.

Единый Envelope используется для всех событий: один channel соответствует одному event_type.

Содержание

  • SMS-сообщения
  • Биллинг SMS

Общий формат события

Все события используют общую обёртку Envelope:

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; одинаков при повторных доставках и используется для дедупликации
dataobject✓Данные, специфичные для event_type

✓ — обязательное поле; — — необязательное.

Для каждого события приведены описание полей data и пример Payload.

SMS-сообщения

Sms_event - Входящее/исходящее СМС

Описание: Событие о входящем/исходящем СМС
Payload: allOf — общий Envelope + данные события.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные, специфичные для event_type

data

ПолеТипОбяз.Описание
datenumber✓Метка времени отправки сообщения
client_account_idnumber✓Номер лицевого счёта клиента
message_codingnull✓Кодировка SMS-сообщения
eventTypestring✓Тип события
messagestring✓Текст сообщения
typestring✓Тип SMS: p2p — между абонентами, a2p — от приложения абоненту
src_numberstring✓Номер отправителя (номер A)
accountIdnumber✓Номер лицевого счёта; дублирует account_id из Envelope
sent_timenumber✓Unix-время отправки SMS, микросекунды
idnumber✓ID SMS-сообщения во внутренней системе
dst_numberstring✓Номер получателя (номер B)
smscstring✓Идентификатор SMS-центра (SMSC), через который отправлено сообщение
directionstring✓Направление SMS: incoming — входящее, outgoing — исходящее

✓ — обязательное поле; — — необязательное.

Пример: Payload

 "account_id": 10001,
  "event_type": "sms_event",
  "created_at": "2026-07-01T18:34:48.548Z",
  "idempotencyKey": "5b133904-6192-49d2-abbc-f95be887fb70",
  "data": {
    "date": 1782920088283097,
    "client_account_id": 10001,
    "message_coding": null,
    "eventType": "sms_event",
    "message": "Текст входящего СМС",
    "type": "p2p",
    "src_number": "Example",
    "accountId": 10001,
    "sent_time": 1782920088279568,
    "id": 7979973,
    "dst_number": "+79000000004",
    "smsc": "yate-smsgw",
    "direction": "incoming"
  }
}
