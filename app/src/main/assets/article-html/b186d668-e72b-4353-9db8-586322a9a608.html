Авторизация по звонку

События (вебхуки и триггеры), связанные с авторизацией пользователей с помощью телефонного звонка.

Единый Envelope используется для всех событий: один channel соответствует одному event_type.

Содержание

  • Flash Call
  • Password Call

Общий формат события

Все события используют общую обёртку Envelope:

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; одинаков при повторных доставках и используется для дедупликации
dataobject✓Данные, специфичные для event_type

✓ — обязательное поле; — — необязательное.

Для каждого события приведены описание полей data и пример Payload.

Flash Call

FlashCall - Авторизационный звонок

Событие: Звонки FlashCall
Payload: allOf — общий Envelope + данные события.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные, специфичные для event_type

data

ПолеТипОбяз.Описание
linkedidstring✓ID связанного звонка, объединяет все плечи одного вызова
stop_timestring✓Момент окончания звонка (ISO 8601)
apiRawsarray<any>✓Сырые ответы внешних API, использованных при звонке; служебное поле для отладки
q931_statusnumber✓Статус Q.931 — протокола управления соединениями ISDN
numberstring✓Номер, на который выполняется звонок
final_statusstring✓Финальный статус звонка
sip_ipstring✓IP-адрес SIP-сигнализации звонящей стороны
sip_call_hash_idstring✓Хэш-идентификатор SIP-вызова
uniqueidstring✓Уникальный ID call-leg, формат {systemName}-{timestamp}.{seq}
verification_call_uuidstring✓ID связи звонка с вызовом API
extra_info_idstring✓Доп. метаданные вызова в JSON-строке (например ID автодозвона)
object_typestring✓Тип канала связи (например pstn)
sip_portstring✓Порт SIP-сигнализации звонящей стороны
eventTypestring✓Название события
server_idnumber✓Внутренний ID сервера, обработавшего событие
call_idstring—Идентификатор звонка
call_leg_idnumber✓Числовой ID плеча звонка
accountIdnumber✓Номер лицевого счёта; дублирует account_id из Envelope
vpbx_idnumber✓Номер ВАТС
start_timestring✓Момент начала звонка (ISO 8601)
account_idnumber✓Номер ЛС
origboolean✓Признак исходящей стороны (orig), а не принимающей (term)
call_id_md5string—MD5-хэш идентификатора звонка
channamestring✓Имя канала Asterisk
last_linked_idstring✓linkedId предыдущего связанного звонка при повторном дозвоне
hangup_causestring✓Причина завершения звонка
didstring✓Номер Flash Call

✓ — обязательное поле; — — необязательное.

Password Call

PasswordCall - Авторизационный звонок

Событие: Авторизация через звонок
Payload: allOf — общий Envelope + данные события.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные, специфичные для event_type

data

ПолеТипОбяз.Описание
callIdstring✓Идентификатор звонка
redirectboolean✓Признак переадресации
linkedIdstring✓ID связанного звонка
codestring✓Код звонка
finalStatusstring✓Статус ответа
callerNumberstring✓Номер звонящего абонента
dateReceivedAtUTCstring✓Время получения события Kafka-коннектором в UTC, до микросекунд
channelstring✓Имя канала Asterisk (SIP/PJSIP, Local и др.)
eventTypestring✓Тип события
uuidstring✓Уникальный ID авторизационного звонка
durationnumber✓Длительность вызова/сессии, секунды
accountIdnumber✓Номер аккаунта
langstring✓Язык голосового оповещения
eventstring✓Дублирует event_type — служебное поле Asterisk UserEvent
calledNumberstring✓Номер, на который был совершён звонок
uniqueIdstring✓Уникальный ID call-leg, формат {systemName}-{timestamp}.{seq}
q931Statusstring✓Код ответа
timestampstring✓Момент события (ISO 8601)
vpbxIdstring✓Номер ВАТС

✓ — обязательное поле; — — необязательное.
