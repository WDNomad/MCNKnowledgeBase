Контакт-центр

События (вебхуки и триггеры), связанные с обращениями и диалогами Контакт-центра.

Единый Envelope используется для всех событий: один channel соответствует одному event_type.

Содержание

  • Обращения
  • Диалоги

Общий формат события

Все события используют общую обёртку Envelope:

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; одинаков при повторных доставках и используется для дедупликации
dataobject✓Данные, специфичные для event_type

✓ — обязательное поле; — — необязательное.

Для каждого события приведены доступное описание полей data и пример Payload.

Обращения

Ticket_created - Контакт-центр: создание обращения

Схема события пока недоступна. Событие присутствует в продукте, но отсутствует в выгрузке БД — специфичные поля data и пример payload недоступны.

Payload: общий Envelope. Структура data не определена.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные события; структура пока недоступна

✓ — обязательное поле; — — необязательное.

Пример: Payload

{
  "account_id": 0,
  "event_type": "string",
  "created_at": "2019-08-24T14:15:22Z",
  "idempotencyKey": "0c14c6a6-6f50-4d1e-b0c4-b46ff43ba6a1",
  "data": {}
  }
}

Диалоги

Subdialog.created - Контакт-центр: создание диалога

Payload: allOf — общий Envelope + данные события.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные, специфичные для event_type

data

ПолеТипОбяз.Описание
accountIdnumber✓Номер лицевого счёта
subdialog_idnumber✓ID под-диалога в контакт-центре
external_idstring✓Внешний ID, связывающий под-диалог с исходным звонком/обращением
sourcestring✓Источник обращения в контакт-центр (например vpbx)
statestring✓Внутреннее состояние под-диалога; дублирует status
eventTypestring✓Дублирует event_type события
statusstring✓Статус под-диалога (например in_queue — в очереди)

✓ — обязательное поле; — — необязательное.

Пример: Payload

{
 "account_id": 10001,
  "event_type": "subdialog.created",
  "created_at": "2026-07-01T22:48:49.036Z",
  "idempotencyKey": "5b133904-6192-49d2-abbc-f95be887fb70",
  "data": {
    "accountId": 10001,
    "subdialog_id": 17079732,
    "external_id": "125-1782935328.12200710",
    "source": "vpbx",
    "state": "IN_QUEUE",
    "eventType": "subdialog.created",
    "status": "in_queue"
  }
}

Payload: allOf — общий Envelope + данные события.
