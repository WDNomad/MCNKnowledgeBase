1. Согласование и подключение Альфа-имени

⚠️Важно!Альфа-имя нельзя создать самостоятельно в разделе «Альфа-номера». Сначала его необходимо согласовать через АКМ и зарегистрировать в биллинге. После этого Альфа-имя появится в Личном кабинете и будет доступно для выбора.

Перед настройкой SMS-информирования:

a. Согласуйте необходимое Альфа-имя через АКМ.
b. После согласования Альфа-имя необходимо зарегистрировать в биллинге.
c. Дождитесь появления Альфа-имени в списке доступных значений в Личном кабинете.

2. Создание и активация Альфа-номера

a. Перейдите в раздел «Альфа-номера».
b. Создайте новый Альфа-номер.
c. В поле «Альфа-имя» выберите из выпадающего списка ранее согласованное и зарегистрированное в биллинге Альфа-имя.

d. После создания Альфа-номера нажмите ⋮ рядом с ним.
e. Выберите «Открыть карточку».
f. Нажмите «Активировать».

  • После активации Альфа-номер можно использовать при создании задания на SMS-информирование.

3. Создание группы контактов, которым необходимо отправить SMS

⚠️Важно!Если контакт уже существует в адресной книге, добавить его непосредственно при создании специальной группы нельзя. Добавьте контакт в группу через «Адресную книгу».

  • Чтобы добавить существующий контакт в группу:

    1. Перейдите в раздел «Адресная книга».

    2. Выберите нужный контакт и нажмите «Добавить в группу».

    3. Выберите ранее созданную группу.

    4. Нажмите «Подтвердить».

  • Массовое добавление контактов из CSV-файла

    Также вы может загрузить сразу несколько контактов CSV-файлом. Подробнее см. «Адресная книга → Импорт контактов».

4. Создание задания на SMS-информирование

a. Перейдите в раздел «СМС Информирование».
b. Нажмите «Создать».
c. Заполните параметры задания:

  • Название задания — укажите название длиной не менее 3 символов.
  • Группа контактов — выберите подготовленную группу получателей.
  • Альфа-номер — выберите ранее созданный и активированный Альфа-номер.
  • Скорость обработки звонков и период — укажите необходимые параметры.
  • Настройки времени выполнения задач — задайте время выполнения.
  • Расписание — настройте расписание отправки.
  • Часовой пояс — выберите необходимый часовой пояс.
  • Текст сообщения — введите текст SMS.
  • Переменные из группы контактов — при необходимости добавьте в текст сообщения переменные, доступные для выбранной группы.

d. Нажмите «Сохранить».

5. Модерация задания

  • После сохранения задание получит статус «На модерации».

a. Нажмите «Модерация».
b. Дождитесь завершения модерации.
c. После успешной модерации статус задания изменится на «Готово к старту».

6. Запуск задания

Когда задание получит статус «Готово к старту», запустите его.
