Коллтрекинг

События (вебхуки и триггеры), связанные с работой Коллтрекинга.

Единый Envelope используется для всех событий: один channel соответствует одному event_type.

Общий формат события

Все события используют общую обёртку Envelope:

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; одинаков при повторных доставках и используется для дедупликации
dataobject✓Данные, специфичные для event_type

✓ — обязательное поле; — — необязательное.

Для события приведены описание полей data и пример Payload.

Звонок из Коллтрекинга

Calltracking_call - Звонок из коллтрекинга

Описание: Звонок из коллтрекинга
Payload: allOf — общий Envelope + данные события.

Envelope

ПолеТипОбяз.Описание
account_idinteger✓ID аккаунта в системе
event_typestring✓Тип события — см. components/messages
created_atstring (date-time)✓Момент события (UTC)
idempotencyKeystring (uuid)—Ключ идемпотентности; используется для дедупликации повторных доставок
dataobject✓Данные, специфичные для event_type

data

ПолеТипОбяз.Описание
google_idstring✓ID клика Google Ads, связанный со звонком
utm_mediumstring✓UTM-метка medium
ya_tracker_idstring✓ID счётчика Яндекс Метрики
durationnumber✓Длительность разговора
event_typestring✓Дублирует event_type события внутри data
connect_timestring✓Время соединения
repeatnumber✓Признак повторного звонка
utm_contentstring✓UTM-метка content
google_tracker_idstring✓ID трекера Google Ads, связанный со звонком
channel_namestring✓Название рекламного канала коллтрекинга
linkedIdstring✓ID связанного звонка
utm_campaignstring✓UTM-метка campaign
mcn_callidstring✓Внутренний ID звонка в системе коллтрекинга
eventTypestring✓Тип события
utm_termstring✓UTM-метка term
last_locationstring✓Последняя страница/раздел сайта перед звонком
accountIdstring✓Номер лицевого счёта; дублирует account_id из Envelope
sitestring✓Страница трекера
account_idstring✓Номер ЛС
phonestring✓Номер телефона
ya_client_idstring✓ID посетителя Яндекс Метрики
