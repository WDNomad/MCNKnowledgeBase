⚠️Внимание!Настройку может проводить пользователь только с правами «Владелец» или «Администратор».

Данные из личного кабинета MCN Telecom:

  1. Номер ЛС — на любой странице личного кабинета в верхней панели экрана.

  2. Номер виртуальной АТС — раздел «ВАТС 2.0» → вкладка «Телефонная система» → меню слева «Номера» → в колонке «Услуга».

  3. Токен — раздел «Интеграции» → вкладка «Токены» → вкладка «Токены API». Подробнее см. «Как получить токен».

  4. Внутренние номера и ID пользователя (для передачи вашему менеджеру в Staff365)— раздел «ВАТС 2.0» → вкладка «ВАТС» → меню слева «Номерной план» → «Номера абонентов» → в колонках «Номер абонента» и «ID пользователя».

В личном кабинете CRM Staff365:

⚠️Внимание!Настройку может проводить пользователь только с правами «Администратор».

  1. В главном меню через три черточки в левом верхнем углу → откройте «Настройки» → «Настройки CRM».

  2. В открывшемся меню слева разверните раздел «Интеграция» и нажмите на пункт «Интеграция с облачными АТС», а затем в правом верхнем углу нажмите «Изменить».

  3. В появившемся окне последовательно:

    1. Отметьте галочкой «Использовать данного провайдера ВАТС при осуществелении click2call».
    2. В списка «ВАТС по-умолчанию» выбираем значение «Mcn».
    ⚠️Внимание!Поле «MCN crm token» оставьте пустым!!!

    1. В поле «MCN API url» впишите фиксировано https://integrationv2.mcn.ru/api/protected/api/

    2. В поле «MCN api token» — вставьте токен из личного кабинета MCN Telecom.

    3. В поле «MCN accound id» — впишите номер лицевого счета MCN Telecom.

    4. В поле «MCN PBX id» — впишите номер виртуальной АТС MCN Telecom.

    5. Нажите «Сохранить».

    6. Нажите «Зарегистрировать уведомления от провайдера ВАТС».

  • После обновления страницы в поле «MCN crm token» должно появиться значение токена.

  • Далее, в личном кабинете MCN зайти на вкладку «Интеграции» → «Веб-хуки» и проверить, создались ли следующие вебхуки:

    • inbound start — ВАТС: Начало входящего звонка

    • inbound answer queue — Ответ на звонок через очередь

    • inbound answer — Ответ на звонок

    • inbound end — ВАТС: Завершение входящего звонка

    • inbound connected direct — ВАТС: Начало звонка на внутренний номер

    • outbound start — ВАТС: Начало исходящего звонка

    • outbound answer — ВАТС: Исходящий звонок отвечен

    • outbound end — ВАТС: Завершение исходящего звонка

    • inbound connected queue — Начало звонка на абонента в очереди

    • record ready — Готовность файла записи разговора

  • Если веб-хуки создались и в поле «MCN crm token» появилось значение токена – значит интеграция прошла успешно.
