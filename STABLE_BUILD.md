## Как вернуться к исходникам

Сначала сохранить текущую работу отдельным коммитом или через `git stash`. Затем создать новую ветку от контрольной версии:

```sh
git fetch origin --tags
git switch -c restore-stable-2026-09-28 stable-2026-09-28
```

Для обычной установки достаточно скачать APK из релиза. Возврат к исходникам и повторная сборка не гарантируют побайтово идентичный APK; для точного установочного файла использовать сохранённый артефакт и его контрольную сумму.
