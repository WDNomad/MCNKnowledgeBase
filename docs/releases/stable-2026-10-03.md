# MCN Knowledge Base 1.1.1 — стабильная контрольная версия

Дата фиксации: 03.10.2026. Git-тег: `stable-2026-10-03`.

Это точка восстановления текущего приложения: тег закрепляет исходники, а GitHub Release содержит готовый APK и SHA-256 для проверки файла. Предыдущая контрольная версия `stable-2026-09-28` остаётся доступной.

## Что входит в версию

- Четыре уровня каталога и поиск по всей базе, разделу или подразделу.
- Выбор аудитории при запуске с возможностью запомнить его; частные лица начинают с раздела MCNmobile.
- Форматированные статьи с изображениями на исходных местах, светлая и тёмная тема в палитре MCN.
- Загрузка всей базы или выбранного раздела для чтения без сети, отмена и докачка с учётом уже сохранённых статей.
- Внутренние переходы по ссылкам, история статей, обработка ссылок на текущую статью и кнопка «Главная страница».
- Распознавание старых адресов базы знаний и переходов в другие разделы по UUID. Ссылки старой базы без UUID сопоставляются по точному уникальному названию.
- Новая адаптивная иконка с книгой и бирюзовой закладкой; отдельный одноцветный вариант для тематических иконок Android.

## Сборка и проверки

Android 8.0 / API 26 и выше. `versionName = 1.1.1`, `versionCode = 3`.

```powershell
.\gradlew.bat :app:assembleRelease :app:testDebugUnitTest :app:lintRelease
```

Unit-тесты общих компонентов выполняются для debug-варианта; устанавливаемый APK собран из release-варианта с выключенным режимом отладки. Автоматические тесты проверяют каталог, HTML, ссылки, реальный стек Android Navigation, выбор аудитории и логику докачки. Иконка визуально проверена в круглой и квадратной масках, при размере 48 пикселей и в одноцветных светлом/тёмном вариантах.

При фиксации успешно выполнены release-сборка и 39 unit-тестов (без ошибок и пропусков). Lint release: 0 ошибок, 45 предупреждений. Подпись APK проверена Android `apksigner`.

Для личного обновления сохранён прежний локальный Android debug-сертификат. Его SHA-256: `328e6c0370fb8d5ef5d8a0faa5482c048cbff887c4f74ff8dba3c5ca7aaf8f1d`. Подпись совпадает с предыдущей стабильной сборкой; установка новой версии поверх неё сохраняет внутренние данные приложения. Отдельного ключа для публичного распространения эта версия не создаёт.

## Границы проверки

Встроенный каталог содержит 805 статей; HTML 30 статей включён в APK. Для первого получения остальных оформленных статей и изображений нужна сеть. Видео и интерактивные элементы не сохраняются.

После исправления ссылок живую страницу FAQ из пользовательского примера получить не удалось из-за недоступности сайта. Переданный целевой URL «Настройки очереди» распознаётся по UUID и покрыт тестом; фактический переход из этой страницы ещё требует проверки в приложении. Проверка на физическом устройстве и Android instrumentation-тесты при фиксации не выполнялись.

## Восстановление исходников

Чтобы получить отдельную копию сохранённого кода, не меняя текущую рабочую папку:

```powershell
git worktree add ../MCNKnowledgeBase-stable-1.1.1 stable-2026-10-03
```

APK выпуска: `MCNKnowledgeBase-1.1.1-stable-2026-10-03.apk`. Контрольная сумма находится в `SHA256SUMS.txt` рядом с APK в GitHub Release и локальной папке стабильных сборок.
