# MCN Knowledge Base

Android-приложение на Kotlin и Jetpack Compose. Основной проект расположен в этой папке, отдельно от родительского проекта MyMCN.

## Четыре экрана

1. Главная: все разделы и поиск по всей русской базе.
2. Раздел: его подразделы и поиск среди всех статей раздела.
3. Подраздел: список статей и поиск только в выбранном подразделе.
4. Статья: форматированный текст с изображениями на исходных местах, списками, таблицами, ссылками и путём в каталоге.

Поиск учитывает заголовок и текст, игнорирует регистр и различие «е/ё». Все введённые слова должны встретиться в документе. Результаты открывают статью напрямую; возврат сохраняет запрос и положение списка благодаря Navigation Compose и rememberSaveable.

Источник структуры — `https://handbook.mcn.ru/sitemap.xml`. Для `/ru/virtualnaya-ats/nastroyka/document--UUID/` разделом становится `virtualnaya-ats`, подразделом — `virtualnaya-ats/nastroyka`. Полный путь исключает смешивание одноимённых подразделов. Документы без подраздела доступны в «Общих статьях». Более глубокие пути сохраняются как отдельные группы на третьем экране.

## Светлая и тёмная тема

Оформление следует системной теме Android. Статья получает явные цвета из той же палитры Material, что и меню приложения, включая динамические цвета Android 12+. Для текста, ссылок, подписей, таблиц и блоков кода предусмотрены отдельные цвета. Автоматическое затемнение WebView отключено: фотографии и скриншоты сохраняют исходные цвета. Переключение темы обновляет оформление сохранённой статьи без повторной загрузки её содержимого.

## Данные и обновление

В `app/src/main/assets` находится встроенный снимок русских статей. Он обеспечивает первый запуск, чтение и поиск без интернета.

При первом открытии статьи приложение получает HTML с handbook.mcn.ru и извлекает только содержимое документа. Изображения остаются внутри исходных абзацев и списков. HTML очищается от скриптов и элементов интерфейса сайта и отображается в WebView с отключённым JavaScript и доступом к локальным файлам. Размер изображений адаптируется к экрану, широкие таблицы прокручиваются по горизонтали. Ссылки открываются внешним приложением.

HTML и успешно загруженные изображения сохраняются в постоянном хранилище приложения. Повторное открытие работает без интернета; кнопка «Обновить статью» повторяет загрузку оформления и отсутствующих картинок. Для 30 уже полученных страниц HTML встроен в APK. Для остальных статей первоначальная загрузка оформления требует интернета. Если её выполнить невозможно, остаётся сохранённый текст и сообщение об ошибке; картинки не переносятся в конец статьи. Незагруженные изображения заменяются поясняющей заглушкой на том же месте. Внешние видео и интерактивные виджеты в этой версии не встраиваются.

Кнопка «Обновить» загружает `articles.json` с GitHub Pages репозитория WDNomad/knowledge-base-data. Новые версии выбираются по `updatedAt`; более старая выгрузка не удаляет встроенные статьи и не откатывает свежий текст. Сохранение в Room выполняется одной транзакцией. При сетевой ошибке на экране остаётся доступная копия и сообщение с повторной попыткой. Это первоначальный механизм объединения: автоматическое удаление устаревших статей и ежедневное серверное обновление пока не реализованы.

`knowledge-base-parser` содержит предшествующий парсер. Для подготовки текущего снимка добавлен `tools/build_catalog.py`: он использует актуальный sitemap, переиспользует тексты из соседнего `knowledge-base-data/articles.json`, скачивает недостающие документы и сохраняет результат в assets. Новые документы содержат также `contentHtml`, а доступные загруженные страницы экспортируются в `assets/article-html`. Уже существующие тексты не скачиваются повторно; свежесть их содержимого соответствует исходной выгрузке. Названия разделов берутся из `categories.json`, читаемые названия подразделов — из `tools/subsection_titles.json`. При добавлении новых подразделов их названия следует дополнить; до этого интерфейс покажет slug с пробелами.

```powershell
curl.exe --fail --location https://handbook.mcn.ru/sitemap.xml -o sitemap-source.xml
python tools/build_catalog.py --sitemap sitemap-source.xml
```

Скрипт прекращает подготовку, если недостающую статью не удалось получить или распознать. Загрузка не запускается на каждом телефоне. Публикация в GitHub и настройка расписания — отдельный шаг.

## Сборка и проверка

Нужны JDK 21 и Android SDK 36.1; путь к SDK задаётся в локальном `local.properties`.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Проверка на устройстве: открыть «Виртуальная АТС» → «Настройка» → «Выход из очереди в сценарии звонка»; проверить поиск на каждом из трёх уровней, возврат со статьи, очистку запроса, отсутствие результатов, поворот экрана, запуск без сети и ошибку обновления.
