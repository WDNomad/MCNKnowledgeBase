# MCN Knowledge Base — неофициальное приложение

> **Неофициальный фанатский проект для личного использования.** Приложение не разработано и не поддерживается MCN Telecom и не является официальным продуктом компании.

Источник статей — [база знаний MCN](https://handbook.mcn.ru/ru/). Этот репозиторий содержит независимое приложение для удобного чтения этих материалов.

Android-приложение на Kotlin и Jetpack Compose. Основной проект расположен в этой папке, отдельно от родительского проекта MyMCN.

Текущая стабильная контрольная версия: **1.1.1**, тег **`stable-2026-10-03`**. Исходники и APK закреплены в [GitHub Release](https://github.com/WDNomad/MCNKnowledgeBase/releases/tag/stable-2026-10-03). Состав версии и проверки описаны в [заметках к выпуску](docs/releases/stable-2026-10-03.md). Предыдущий тег `stable-2026-09-28` сохранён.

## Четыре экрана

При запуске предлагается выбрать «Для юридических лиц» (общий каталог) или «Частным лицам» (сразу раздел «База знаний абонентов MCNmobile»). Галочка «Запомнить выбор» сохраняет один выбранный вариант в SharedPreferences. Без галочки предыдущая настройка удаляется, и при следующем новом запуске выбор появляется снова. Возврат к приложению из фона и поворот экрана сохраняют текущую навигацию.

Изменить сохранённый выбор можно через «⋮» → «Изменить выбор аудитории» на экранах каталога. Изменение применяется после нажатия одной из двух кнопок; кнопка «Назад» отменяет смену. Выбор не ограничивает доступ: из стартового раздела MCNmobile можно вернуться в общий каталог стрелкой «Назад».

1. Главная: все разделы и поиск по всей русской базе.
2. Раздел: его подразделы и поиск среди всех статей раздела.
3. Подраздел: список статей и поиск только в выбранном подразделе.
4. Статья: форматированный текст с изображениями на исходных местах, списками, таблицами, ссылками и путём в каталоге.

Гиперссылки на статьи handbook.mcn.ru из текущего каталога открываются внутри приложения. Переходы добавляются в историю: системный жест/кнопка «Назад» и стрелка возвращают к предыдущей статье с сохранением прокрутки. Ссылка на текущую статью не добавляет экран; якоря перемещают к нужному месту. Для поиска статьи используется путь или UUID, поэтому изменение slug и параметры ссылки не создают лишних переходов. Если статьи ещё нет в каталоге, приложение предлагает явно открыть сайт. Другие сайты, телефоны и почта открываются внешними приложениями.

«Открыть оригинал статьи» всегда открывает текущий документ на сайте. Кнопка «Главная страница» в статье и каталоге очищает историю переходов и заново читает сохранённый выбор: без него показывает выбор аудитории, для бизнеса — общий каталог, для частных лиц — раздел MCNmobile.

Переход к другой статье создаёт отдельную запись истории, даже если обе статьи используют один маршрут экрана. Только ссылка на текущую статью пропускается. Старые ссылки `kb.mcn.ru` распознаются по UUID; для ссылок старой базы с числовым ID используется точное уникальное название статьи. Ссылки приводятся к текущим адресам при показе HTML, в том числе уже скачанного. Другой раздел назначения не влияет на открытие внутри приложения.

Поиск учитывает заголовок и текст, игнорирует регистр и различие «е/ё». Все введённые слова должны встретиться в документе. Результаты открывают статью напрямую; возврат сохраняет запрос и положение списка благодаря Navigation Compose и rememberSaveable.

Источник структуры — `https://handbook.mcn.ru/sitemap.xml`. Для `/ru/virtualnaya-ats/nastroyka/document--UUID/` разделом становится `virtualnaya-ats`, подразделом — `virtualnaya-ats/nastroyka`. Полный путь исключает смешивание одноимённых подразделов. Документы без подраздела доступны в «Общих статьях». Более глубокие пути сохраняются как отдельные группы на третьем экране.

## Светлая и тёмная тема

Оформление вдохновлено сине-бирюзовой палитрой MCN Telecom: градиентные вводные блоки, карточки с иконками, светлые поверхности и единая типографика. Светлая и тёмная палитры переключаются по системной теме Android; динамические цвета обоев отключены для постоянства оформления. Статья получает явные цвета из той же палитры Material, что и меню приложения. Для текста, ссылок, подписей, таблиц и блоков кода предусмотрены отдельные цвета. Автоматическое затемнение WebView отключено: фотографии и скриншоты сохраняют исходные цвета. Переключение темы обновляет оформление сохранённой статьи без повторной загрузки её содержимого.

Иконка приложения — раскрытая книга с бирюзовой закладкой на синем градиенте. Векторные слои адаптивной иконки и отдельный одноцветный силуэт для тематических иконок Android находятся в `app/src/main/res/drawable/ic_launcher_*.xml`. Символ помещён в безопасную область для разных масок лаунчера. Превью и обычные/круглые WebP для пяти плотностей пересоздаются командой `python tools/render_launcher_icon.py` (нужен Pillow); источник геометрии — те же Android-векторы. Превью: `artwork/launcher-icon-preview.png`.

## Данные и обновление

### Загрузка для чтения офлайн

При нажатии «Докачать» приложение сначала проверяет локальные HTML и все изображения без сетевых запросов. Счётчик сразу учитывает готовые статьи (например, 3 из 6); в очередь попадают только неполные. Полоса прогресса показывает число полностью сохранённых статей. Ошибки предыдущей попытки сбрасываются и учитываются заново, если недостающие файлы вновь не удаётся получить. Проверка работает и для заданий, созданных предыдущей версией приложения.

В каталоге кнопка «Загрузить все статьи» сохраняет всю текущую базу с оформлением и изображениями. Значок загрузки справа от раздела сохраняет только его статьи; внутри раздела и подраздела есть аналогичная кнопка. Поисковый запрос не ограничивает эту загрузку. Тексты уже входят в приложение, дополнительно скачиваются HTML и изображения на исходных местах.

Загрузка использует текущее подключение, в том числе мобильный интернет. На экране показаны количество полностью сохранённых статей, ошибки и отмена. Статья считается готовой только после сохранения всех изображений. Уже имеющиеся HTML и изображения повторно не скачиваются. «Докачать» после отмены или ошибки заново проверяет выбранный набор и сохраняет недостающие файлы, начиная с ещё не обработанных статей. Три ошибки сети/хранилища подряд останавливают пакет, чтобы не продолжать сотни запросов при недоступности сервера или заполненном хранилище. Отдельные отсутствующие страницы (404) не мешают обработке остальных статей.

Одновременно выполняется одно задание WorkManager. Оно не привязано к экрану, хранит контрольные точки и ожидает доступного подключения. Android может отложить фоновую работу; немедленная непрерывная загрузка в фоне не гарантируется. Длинное задание разбито на возобновляемые запуски до семи минут. Принудительная остановка приложения в настройках Android приостанавливает его работу до следующего открытия. Файлы находятся во внутреннем постоянном хранилище приложения. Внешние видео и интерактивные элементы не скачиваются.

В `app/src/main/assets` находится встроенный снимок русских статей. Он обеспечивает первый запуск, чтение и поиск без интернета.

При первом открытии статьи приложение получает HTML с handbook.mcn.ru и извлекает только содержимое документа. Изображения остаются внутри исходных абзацев и списков. HTML очищается от скриптов и элементов интерфейса сайта и отображается в WebView с отключёнными JavaScript и доступом к локальным файлам. Размер изображений адаптируется к экрану, широкие таблицы прокручиваются по горизонтали. Ссылки на статьи каталога открываются внутри приложения, внешние ссылки — соответствующим приложением.

HTML и успешно загруженные изображения сохраняются в постоянном хранилище приложения. Повторное открытие работает без интернета; кнопка «Обновить статью» повторяет загрузку оформления и отсутствующих картинок. Для 30 уже полученных страниц HTML встроен в APK. Для остальных статей первоначальная загрузка оформления требует интернета. Если её выполнить невозможно, остаётся сохранённый текст и сообщение об ошибке; картинки не переносятся в конец статьи. Незагруженные изображения заменяются поясняющей заглушкой на том же месте. Внешние видео и интерактивные виджеты в этой версии не встраиваются.

Кнопка «Обновить» загружает `articles.json` с GitHub Pages репозитория WDNomad/knowledge-base-data. Новые версии выбираются по `updatedAt`; более старая выгрузка не удаляет встроенные статьи и не откатывает свежий текст. Сохранение в Room выполняется одной транзакцией. При сетевой ошибке на экране остаётся доступная копия и сообщение с повторной попыткой. Это первоначальный механизм объединения: автоматическое удаление устаревших статей и ежедневное серверное обновление пока не реализованы.

`knowledge-base-parser` содержит предшествующий парсер. Для подготовки текущего снимка добавлен `tools/build_catalog.py`: он использует актуальный sitemap, переиспользует тексты из соседнего `knowledge-base-data/articles.json`, скачивает недостающие документы и сохраняет результат в assets. Новые документы содержат также `contentHtml`, а доступные загруженные страницы экспортируются в `assets/article-html`. Уже существующие тексты не скачиваются повторно; свежесть их содержимого соответствует исходной выгрузке. Названия разделов берутся из `categories.json`, читаемые названия подразделов — из `tools/subsection_titles.json`. При добавлении новых подразделов их названия следует дополнить; до этого интерфейс покажет slug с пробелами.

```powershell
curl.exe --fail --location https://handbook.mcn.ru/sitemap.xml -o sitemap-source.xml
python tools/build_catalog.py --sitemap sitemap-source.xml
```

Скрипт прекращает подготовку, если недостающую статью не удалось получить или распознать. Загрузка не запускается на каждом телефоне. Публикация в GitHub и настройка расписания — отдельный шаг.

## Сборка и проверка

Нужны JDK 21 и Android SDK 36.1; путь к SDK задаётся в локальном `local.properties`.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Локальная release-сборка версии 1.1.1: `:app:assembleRelease :app:testDebugUnitTest :app:lintRelease`. Общие unit-тесты запускаются для debug-варианта, APK и lint — для release. APK: `app/build/outputs/apk/release/app-release.apk`. Режим отладки выключен; для обновления поверх предыдущих личных сборок используется прежний сертификат из стандартного локального Android debug-keystore. Нового отдельного сертификата для распространения эта конфигурация не создаёт. Установка поверх приложения сохраняет его внутренние данные.

Проверка на устройстве: открыть «Виртуальная АТС» → «Настройка» → «Выход из очереди в сценарии звонка»; проверить поиск на каждом из трёх уровней, возврат со статьи, очистку запроса, отсутствие результатов, поворот экрана, запуск без сети и ошибку обновления.
